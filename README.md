# ADS 实验陪练

面向 Keysight ADS 射频/微波电路初学者的实验教学助手。用步骤指导、理论计算和结果检查，帮助学生发现单位、阻抗、连线及仿真结果中的问题。

## 为什么做这个作品

学习 ADS 时，搭出电路不等于结果正确。初学者容易混淆 mm 与 μm、端口与负载阻抗，也不容易判断 S 参数曲线是否合理。本项目尝试把“怎么做、为什么、如何验证”放在同一个实验页面中。

## 已实现

- 五个实验的指导内容：微带线、理想传输线与四分之一波长变换器、单支节匹配、低通滤波器、Wilkinson 功分器。
- 理论参数计算、知识卡片、基于本地规则库的故障诊断、按姓名保存进度。
- 实验 2 的网表连线检查、ADS 原始数据读取、理论复数 S 参数验证，以及开路/短路等状态的证据留存。
- Windows 双击启动/停止入口，后台采集可在关闭网页后继续运行。

## 运行

需要 Python 3.10+。先安装依赖：

```powershell
python -m pip install -r ads-lab-coach/requirements.txt
```

Windows 下双击 `启动实验陪练.vbs`，使用结束后双击 `停止实验陪练.vbs`。

仅浏览教学页面也可以：

```powershell
cd ads-lab-coach
python -m streamlit run app.py
```

直接运行 Streamlit 不会启动独立后台采集。实验 2 的数据读取需本机安装 Keysight ADS；默认查找 `C:/Program Files/Keysight/ADS*/tools/python/python.exe`，其他位置通过 `ADS_PYTHON` 环境变量配置。

## 方法与证据

实验 2 使用网表识别电路拓扑及参数，通过 ADS 自带的 `keysight.ads.dataset` 接口读取 `.ds` 数据，再用传输线理论核对频率扫描中的复数 S11/S21。不同网页参数独立记录证据。

开发过程中最近一次回归测试为 45 项通过，覆盖理论计算、内容引用、页面控件、五种实验状态、错误结果、参数隔离和证据留存。已读取真实 ADS 开路数据验证：1 GHz 附近 S11 相位约为 −180°。用户实测微带线线宽修正到约 3 mm 后，2.4 GHz 附近 S11 从明显失配改善至约 −35 dB（截图读数，非精密测量）。

```powershell
cd ads-lab-coach
python -m pytest -q
```

## 当前完成度与限制

这是由用户提出需求、在实际 ADS 学习中测试，并借助 AI 协作开发的原型。45 项测试不代表已完成全部真实 ADS 实验验收。

- 实验 2 的五种状态主要以理论构造数据测试，真实全流程验收尚未完成；其他实验使用原有较简单的检测方式。
- 文件轮询可能漏掉快速连续覆盖的中间仿真；每次应等待留存后再改变状态。
- 临时读取失败的重试、实验轮次历史和小组进度同步仍需完善。
- 原有手动步骤勾选和数值输入保留；手动记录不能替代后台仿真验证证据。
- 部分教学步骤仍标为草稿或未经实操验证。仅支持当前实现的理想 TLIN 电路结构，不支持任意 ADS 电路自动评分。
- 项目是本地应用；GitHub 地址用于查看和下载源码，并非云端连接 ADS 的在线仿真服务。

本仓库不包含个人进度数据库、日志、ADS 安装文件和个人仿真工程。首次运行会在本地创建所需数据目录。
